# 大世界分区流式加载

## 决策

将可探索世界固定为 192×128 格、每格 16×16 像素，并按 32×32 格划分为 6×4 个稳定区块。运行时只实例化玩家当前区块及周围 3×3 邻域，离开邻域的区块卸载。

保留原有 48×32 农场为世界左上角家园区，不迁移农业、NPC、商亭和加工设施坐标；通过南侧三格宽石阶接入大世界。探索迷雾使用 `x:y` 稳定区块 ID 保存。

## 原因

- 保留已经验证的教程和经营坐标，避免大地图扩展破坏农业业务状态。
- 192×128 的面积是原农场的 16 倍，能形成自由探索感，同时仍适合当前垂直切片的内容密度。
- 32×32 区块让加载边界可预测；3×3 邻域覆盖相机周围足够缓冲，又避免一次创建全部 24 个区块。
- 确定性世界定义可同时驱动地形、装饰、碰撞、地标和自动测试，避免画面与通行规则漂移。

## 约束

- `WorldDefinition` 是区域、道路、水域、装饰与阻挡的事实来源。
- 场景流式节点只负责投影和生命周期，不拥有任务、农业或存档规则。
- 存档继续使用 `schemaVersion: 1` 的加法字段；旧存档缺失探索数据时默认发现家园区块。
- 农场外的新内容不得假装已经具备完整采集、事件或 NPC 日程系统。

## 验证

- 自动路径搜索已证明南门可到达全部六个地标的相邻格。
- macOS 实机连续穿过南门进入低语林地，区块加载、区域提示与迷你地图揭图正常。
- C# 编译 0 错误、0 警告；核心测试 23/23 通过；Godot 资源导入和无界面大世界启动通过。
