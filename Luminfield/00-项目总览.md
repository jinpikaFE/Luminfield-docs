## 项目定位

Luminfield（微光原野）是一款使用 Godot 4.7.1 .NET 与 C# 制作的原创双语农场生活 RPG 垂直切片。

当前交付覆盖约 15 分钟的完整玩法闭环：

1. 与微光植物学家米菈交谈并领取星芽莓种子。
2. 锄地、播种、浇水和管理体力。
3. 通过睡眠跨日推进作物成长。
4. 收获三株成熟星芽莓并返回米菈完成教程。
5. 保存退出后继续游戏，恢复日期、体力、快捷栏、农田和任务状态。
6. 从农场南门进入 192×128 格大世界，探索七个区域、发现地标并通过迷你地图记录探索进度。
7. 使用手、铲子、柴刀、浇水壶和水桶完成采收、开垦、砍树、挖水晶与取水，并在 24 格背包中保存采集物。
8. 在七日星期循环中查看当天天气与次日预报；雨天自动浇灌已开垦土地。
9. 将可出售物投入星辉货箱，睡眠后查看逐项收入和次日天气的夜间结算。
10. 种植八种数据驱动的原创发光作物；挖掘后的水晶在第 2 天、砍伐后的树木在第 7 天按稳定资源 ID 重新生长。
11. 用微光木和晶辉碎片制作星织储物箱，在家园空闲格预览并放置，再通过“手”打开每箱 16 格独立储物。
12. 在小屋与温室之间的星灯委托板接取种植、采集或交付委托，在 HUD 追踪进度并领取微光币奖励。
13. 在低语林地修复林地守望星灯，分批完成三组星图节点，永久把该区域树木再生周期从 7 天缩短为 4 天。
14. 制作并放置月石道路、星木围栏、星光火炬和露滴洒水器；洒水器在睡眠成长结算前自动浇灌相邻四格。
15. 用微光木与晶辉碎片制作星壤肥，在播种前施用于已开垦空土；收获时稳定产出普通、莹润或星辉品质，并在加工、委托、货箱与商店中保留对应品质价值。
16. 沿大世界道路进入微光村，查看 11 处原创外部地标，与 16 名按普通日、灯憩日与条件路线换位的村民交谈、赠礼，并进入月辉档案馆、月石工坊、星织茶屋、暮光商铺、星光邮驿与星落巡守所。
17. 在家园星光邮箱阅读奈米欢迎信，以及莉欧拉、塔维和奈米达到“可信朋友”后次日投递的一次性奖励星邮。
18. 每天 09:00–21:00 进入星织茶屋，查看只读星织茶台，并在普通日 09:00–13:00 与室内工作的维莎交谈或赠礼。
19. 在月辉档案馆按 25/60 关系阈值与跨日顺序体验莉欧拉“褪色的回航线”和“被记住的归途”两阶段友情事件。
20. 普通日每天 10:00–18:00 进入暮光商铺，从按周次与季节确定性轮换的四项种子库存中直接购买；灯憩日整日关闭，并可在 10:00–13:00 与室内工作的奥林交谈或赠礼。
21. 在月石工坊按 25/60 关系阈值与跨日顺序体验塔维“有裂痕的月纹”和“修补过的光”两阶段友情事件。
22. 查看四个 14 天原创季节、季节日与星期；16 名村民会按灯憩日、实际天气和季节优先级选择条件日程。
23. 村民在同一场景内每 10 游戏分钟沿四方向可通行格移动，跨场景从安全入口交接；玩家挡路时等待，寻路失败回退安全锚点。
24. 每天 07:00–19:00 进入星光邮驿，查看只读路线分拣台；奈米普通日 09:00–13:00 在室内工作，并在关系 25/60 点时拥有两阶段午后友情事件。
25. 每天 06:00–20:00 进入星落巡守所，查看只读封印巡路台；凯尔普通日 09:00–13:00 在室内工作，并在关系 25/60 点时体验“断裂的蓝色符纹”与“安全归来的路线”。
26. 在同一块星灯委托板接取“星路修复”每周三阶段委托，按种植、采集、交付顺序推进，并原子领取微光币与月石道路奖励。
27. 在普通日下午的真实广场投影中，按 25/60 关系阈值与跨日顺序体验塞菈“淬炼的星光”和“共同的锻造节奏”两阶段友情事件。
28. 在普通日下午的真实广场投影中，按 25/60 关系阈值与跨日顺序体验奥林“未标价的货单”和“共享灯路”两阶段友情事件；清晨、晚间和灯憩日投影不会误触发。
29. 在月石工坊支付 240 微光币、12 微光木和 4 晶辉碎片启动第一次小屋升级；睡眠两夜后启用原创升级内景与只读厨房，施工状态和完成态均可存档恢复。
30. 在芽辉季购买并种植曦绫花、辉荚藤、雾歌薄荷和彗纹薯；辉荚藤成熟后每浇水两夜可持续采收，小雨与星尘风可分别触发雨织曦绫和星风辉荚。
31. 让月井凝炼器、棱彩蜜渍缸与织星烘叶机独立加工，并按单机领取或原子领取全部已完成产物；新增云纹叶两夜加工链“云纹夜茶”。
32. 通过成功开垦、播种、浇水和收获提升 0–5 级耕作技能，在 3 级永久选择“守露人”或“共鸣学者”。
33. 在芽辉季购买并种植月梅树苗；月梅树三夜成熟、两夜复果，成熟后可用“手”采摘月梅；制作并放置辉巢后，邻近成熟月梅树会推动星蜜产出，采蜜同样使用真实对象高亮和原子入包。
34. 在雨幕季购买并种植涟光菇、潮晶芋、灯穗苇和雨幕莲；商店按季节与季内周次稳定轮换，灯穗苇成熟后每浇水两夜可持续采收，全部四种作物复用现有品质、背包、货箱与存档规则。
35. 第 15–28 天的家园使用原创雨幕季湿润背景，第 14/29 天自动回到基础背景；季相只读取绝对日期，晴朗、小雨、星尘风和长夜雪继续由独立天气层表现。
36. 在星熟季购买并种植鎏金芽、日藏瓜、冠星藏红花和琥珀缕果；琥珀缕果首次成熟后每浇水三夜可持续采收，四种作物复用季节商店、三档品质、货箱、原子预览/动作和 `schemaVersion: 1` 存档规则。
37. 第 29–42 天家园使用原创星熟季背景；家园季相只从绝对日期派生，天气继续由独立覆盖层表现。
38. 在月石工坊原子承建家园工坊，睡眠三夜后启用家园真实工作台；施工项目按稳定 ID 组合保存并兼容旧小屋施工字段。
39. 完成家园工坊后可承建月露温室；四夜后开放独立 24 格跨季农业和月露蓄水池，温室不接受户外雨水或天气共鸣。
40. 第 43–56 天家园使用原创长夜霜封背景，户外新播种被统一预览/动作规则阻止，既有作物继续成长，温室仍可播种；暮光商铺两周轮换八种温室种子。
41. 长夜季第 1、5、8、12 日自然出现 `longnight_snow`；户外玩家移动降低 15%，雪不自动浇水且不进入小屋、温室或村庄室内。旧档当天合法天气优先，固定雪日预报会定向校正。
42. 在家园农田前修复家园丰穰星灯，按农业、加工与营建三节点原子提交；完成后露降洒水器永久覆盖户外八个相邻格，家园与林地星灯状态按稳定 ID 独立保存。
43. 星熟季第 11 日 10:00–18:00 可选进入独立星熟集市，与 16 名既有村民参加节日；从作物与三种加工品中提交三件不同家族展品，获得冻结评分、竞价回款、年度奖项和跨年集市券，并在四项节日商店兑换中保持容量/余额失败零修改。
44. 原子承建星羽鸡舍并在三夜后登记首只幼鸡；晴日非长夜 08:00–18:00 自动放牧，恶劣天气和长夜留舍并消耗草甸饲料。喂养、抚摸、成长、0–5 心情、三档品质星羽蛋、背包容量安全领取与出货形成首类动物闭环。
45. 在星羽鸡舍完工后原子承建水岸月绒羊棚，四夜后登记首只幼羊；复用同一动物系统完成晴日放牧、恶劣日喂养、抚摸、三夜成长、三档品质月绒、容量安全收绒架领取与直接出货，动物进度达到 2/3。
46. 月绒畜棚完工后同时幂等登记首只露角兽；与月绒羊共享草甸饲料、逐只放牧、心情和夜结算，四夜成年、两夜产乳，并通过独立凝露乳台按产物家族原子领取普通/莹润/星辉凝露乳，动物进度达到 3/3。
47. 原子承建星织牧务中枢；两栋动物建筑分别保存 28 份饲料和 12 件产物，夜间按建筑整批自动喂养与自动收集，容量不足时零消耗/零清除，控制台存取与中英管理面板完成实机验证。
48. 芽辉季第 4 日 09:00–17:00 可选进入独立芽辉播种祭，与 16 名既有村民参加共享花田活动；四选三种子、每种 4 份临时剂量与十二格真实目标组成 180 分钟挑战，并按家族、和谐行和用时冻结计分。年度尝试/结果、三档奖项、独立花辉币和四项种子兑换可存档恢复，且不消耗普通农业资源。
49. 在星落草甸北部修复草甸和鸣星灯：花潮与馈赠节点按稳定物品家族原子提交，节庆回响只读芽辉播种祭或星熟集市的既有年度结果；完整修复后辉巢寻找成熟月梅树的距离从 4 格永久扩大到 6 格，产蜜周期与数量不变。
50. 在第一次小屋升级与家园工坊完成后承建月炉小屋扩建；四夜后启用真实厨房与 24 格食材柜，四道稳定配方跨背包/食材柜按品质原子选料，料理只入背包并恢复体力。
51. 长夜季第 13 日 17:00–22:00 可选进入独立长夜灯宴；以两道不同料理和一项家园礼物完成共辉星仪，原子获得回礼、年度奖项与独立灯愿结，仪式不修改区域星灯状态。

53. 完成艾洛温与维莎各两段 25/60、每段 3 页的关系事件，并在凯尔、塞菈、艾洛温、维莎和奥林第二事件完成后的次日领取一次性关系回信。

59. 在低语林地和星辉草甸按季节采集八种稳定野物；8/8 后领取星路采集册，在迷你地图标记已探索区块内当日尚未拾取的节点。

61. 进入固定五室辉晶地窟，采集四种矿物、升级青铜星纹铲、完成矿物图鉴与晶谷调律星灯；该固定勘探不冒充程序生成矿洞。
62. 进入固定三室星落遗迹试炼，领取月纹短刃，面对 3 种敌人的 6 个实例并使用攻击、闪避和试炼生命；净空房间后取得 4 件遗物并可原子捐赠档案馆，完成遗物/敌人图鉴与第六座遗迹追忆星灯。
63. 在长夜季探索六个非家园区域的霜蓝季相；流式区块原位刷新视觉，不改变天气、资源、碰撞或存档。六光汇聚只提供后续星门调律资格，当前星门图集尚未接入运行时。

## 当前架构

- `src/Core/GameSession.cs` 是唯一全局会话入口，组合时间、背包、农业、果园、动物、多分类图鉴、任务、探索、世界采集、制作、储物、加工机、耕作技能、每日/每周委托、星灯修复、商铺轮换、建筑施工、村庄 NPC、星邮和存档状态。
- `src/Core/` 保存不依赖场景的领域模型和服务。
- `src/Core/FarmSystem.cs` 负责开垦、施肥、播种、浇水、成长、持续采收、品质与天气共鸣收获；稳定品质、播种日和已解析共鸣产物写入农田状态，读档不会重抽。
- `src/Core/OrchardSystem.cs` 负责月梅果树与辉巢状态，保存果树位置、成长夜数、可采摘状态、辉巢位置、产蜜进度和待领取星蜜；预览与动作由 `GameSession` 统一接入，失败不消耗树苗、材料、体力或容量。
- `src/Core/WorldResourceSystem.cs` 负责树木、水晶等世界资源的工具匹配、体力消耗、掉落、耗尽日期和按类型再生。
- `src/Core/CalendarWeatherSystem.cs` 负责七日星期、四个 14 天季节、当前天气、长夜 14 日自然天气表、确定性预报与天气存档恢复。
- `src/Core/ShippingBinSystem.cs` 负责货箱队列、撤回和夜间结算；所有物品变更继续通过 `Inventory` 原子执行，已结算明细保存当时有效单价，不由后续奖励状态重算历史。
- `src/Core/ProcessorSystem.cs` 以稳定机器 ID 保存三台加工机的独立配方、剩余夜数和完成态；批量领取先模拟全部背包结果，失败不修改机器或库存，并兼容旧单队列迁移。
- `src/Core/FarmingSkillSystem.cs` 保存 0–5 级耕作经验和 3 级永久二选一专精；只有成功农业动作获得经验，守露人降低浇水体力，共鸣学者提高收获经验。
- `src/Core/AnimalSystem.cs` 以稳定建筑/物种/固定实例 ID 组合保存星羽鸡、月绒羊与露角兽的年龄、心情、当日喂养/抚摸、产物进度和待领取品质产物；建筑/物种/首只目录、逐实例放牧、多建筑夜结算与分建筑自动喂收共享同一领域模型，施工只决定建筑/自动化是否启用，跨系统事务由 `GameSession` 原子编排。
- `src/Core/CraftingSystem.cs` 依据稳定配方 ID 检查材料并通过 `Inventory.TryExchange` 原子制作；`src/Core/StorageSystem.cs` 负责木箱放置规则、每箱 16 格内容与存档投影。
- `src/Core/FarmObjectSystem.cs` 负责道路、围栏、火炬与洒水器的共享放置检查、碰撞属性、四向自动浇水和存档投影；放置检查会额外避开果树与辉巢占位，避免农场实体重叠。
- `src/Core/DailyCommissionSystem.cs` 负责每日确定性轮换、接取、进度、过期与原子领奖；交付数量始终从 `Inventory` 派生。
- `src/Core/WeeklyCommissionSystem.cs` 独立保存周数、当前阶段、进度与领取态；最终交付通过一次 `Inventory.TryExchange` 同时扣除材料并加入物品奖励，成功后再增加微光币。
- `src/Core/TwilightEmporiumSystem.cs` 依据日期、分钟、季节与绝对周次提供统一营业规则和确定性四项种子库存；购买继续由 `GameSession` 做场景、营业、库存、金币与容量的原子校验。
- `src/Core/ConstructionSystem.cs` 以稳定项目组合保存小屋两次升级、家园工坊、温室、两座动物建筑与牧务中枢；全局只允许一个在建项目，开工前完整校验前置、金币与材料并原子扣除，legacy 根仍只镜像第一次小屋升级。
- `src/Core/StarlightSystem.cs` 以稳定星灯 ID 组合保存六座星灯的节点贡献、里程碑、一次性激活与存档归一化；legacy 根字段只镜像林地，所有背包提交继续通过 `Inventory.TryRemoveFamilies` 原子执行。
- `src/Core/FestivalSystem.cs` 以稳定节日/活动/奖励/商店 ID 保存四个主节日的年度结果、未完成尝试和四套独立货币；展品、播种、灯宴仪式、流萤放流与各自兑换都先完整模拟，再由 `GameSession` 原子提交。
- `src/Core/VillageSystem.cs` 以稳定人物 ID 保存 16 名村民的相遇、关系和互动日期；`src/Core/NpcScheduleSystem.cs` 从日期、实际天气、季节、时段与玩家占位批量解析条件目标和格级移动，场景只读取同一当前投影。
- `src/Core/MailSystem.cs` 以稳定邮件 ID 保存送达、已读和附件领取状态；关系奖励在条件达成后的次日投递，附件通过 `Inventory` 原子领取。
- `src/Core/CharacterEventSystem.cs` 以稳定事件 ID、关系阈值、场景、日程对话键和前置事件完成日解析 16 条角色事件链；目录验证人物、前置顺序、严格递增阈值、互异对白页与同人链，活动事件不可被覆盖，只保存已完成事件与完成日期，不创建第二份 NPC 状态。
- `src/Core/CollectionSystem.cs` 按八个分类保存稳定条目的发现、初始化、遗物捐赠与已领取奖励；成功取得物品或真实击败敌人才登记，旧档按新增分类分别做一次证据回填。四个主要奖励继续驱动种子价格、料理体力、工艺品售价和采集地图标记。
- `src/Core/StarfallRuinsTrialSystem.cs` 与 `CombatSystem.cs` 保存固定三室试炼的净空房间、短刃领取、遗物取得，以及仅在当前尝试中的敌人生命、位置、攻击/闪避冷却与玩家试炼生命；失败恢复和存档归一化由 `GameSession` 统一编排。
- `GameSession.PreviewSelectedTarget` 和 `TargetPreview` 提供无副作用的统一目标预览，场景层据此绘制对象轮廓、动作和阻塞原因；果树与辉巢使用独立对象类型并吸附真实实体位置。
- `src/Game/Main.cs` 负责标题、农场、小屋、HUD、对话、暂停和完成画面的切换。
- `src/Core/WorldDefinition.cs` 定义世界尺寸、七个区域、道路、地标与稳定区块 ID；微光村的边界、道路、建筑碰撞和装饰索引继续来自领域定义。
- `src/Game/WorldSeasonVisualCatalog.cs` 只按绝对日期选择基础、雨幕、星熟或长夜的大世界视觉 profile；`WorldChunkStreamer` 把同一 profile 和透明 4×4 图集推送到已加载与新加载区块，不持有或保存第二份季节状态。
- `src/Game/FarmView.cs`、`WorldStreaming.cs`、`FarmVisualLayers.cs` 和 `CottageView.cs` 负责世界表现、流式加载与交互。
- `assets/pixel/` 保存可维护的原创像素 SVG 精灵表。
- `localization/` 使用稳定本地化键提供中英文文本。
- `tests/Luminfield.Tests/` 覆盖时间、农业、背包、任务、本地化和存档行为。

## 维护规则

1. 新任务开始前核对仓库路径、分支、HEAD 和工作区状态。
2. 记录变更时必须区分 HEAD 中的已提交基线与当前未提交工作，不得把工作区修改描述为已提交成果。
3. 代码、存档格式和游戏数值以当前仓库为准；Obsidian 只保存跨任务稳定结论。
4. 经过验证的实现任务写入当天变更记录；模块、决策和排错页只记录长期有效内容。
5. 未经用户明确授权，不自动提交、推送或切换分支；并行任务仍按授权创建一任务一 Worktree，但每轮完成、集成且核对干净后立即清理本轮 Worktree，默认保留分支与提交。
6. 仓库根目录 `AGENTS.md` 固定交互预览、美术、本地化、存档与验证规则；后续功能必须遵守目标高亮契约。
7. 开始实现前先读四篇架构护栏，再按任务读取对应业务模块；不得只依赖历史变更记录恢复上下文。
8. 改变状态所有者、依赖方向、稳定 ID、存档或原子动作语义时，必须同步模块文档并新增或更新决策记录。
9. 本 Vault 使用独立 Git 仓库同步知识；修改前先 `git pull --ff-only`，修改后按主题提交并及时 `git push`。
