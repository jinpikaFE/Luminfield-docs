# 状态所有权与依赖方向

## 所有权表

| 状态 | 唯一所有者 | 存档投影 | 主要只读消费者 |
| --- | --- | --- | --- |
| 日期与分钟 | `GameClock` | `Day`、`MinuteOfDay` | HUD、日程、天气、商铺、委托 |
| 背包与选中格 | `Inventory` | `Inventory`、`Player.SelectedSlot` | 快捷栏、背包、动作预览 |
| 体力、水量、金币、位置 | `GameSession` | `Player`、`Coins` | HUD、场景切换、动作校验 |
| 农田与作物 | `FarmSystem` | `FarmTiles` | 农场绘制、预览、任务和加工入口 |
| 果树与蜂巢 | `OrchardSystem` | `Orchard` | 农场绘制、预览、采摘、采蜜和实体占位 |
| 加工机 | `ProcessorSystem` | `Processor` | 加工面板、地图机器状态 |
| 耕作经验与专精 | `FarmingSkillSystem` | `FarmingSkill` | 技能 HUD、浇水成本、收获经验 |
| 世界探索 | `ExplorationSystem` | `Exploration` | 区块加载、迷你地图 |
| 世界资源 | `WorldResourceSystem` | `Resources` | 世界投影、采集预览、夜间提示 |
| 天气 | `WeatherSystem` | `Weather` | 农业、世界视觉、NPC 日程和 HUD |
| 货箱 | `ShippingBinSystem` | `Shipping` | 货箱面板、夜间结算 |
| 木箱与放置物 | `StorageSystem`、`FarmObjectSystem` | `Storage`、`FarmObjects` | 农场碰撞、面板与对象绘制 |
| 每日/每周委托 | 对应 Commission System | `Commission`、`WeeklyCommission` | HUD、公告栏 |
| 星灯修复 | `StarlightSystem` | `Starlight` | 世界外观、资源再生规则 |
| NPC 关系与日程 | `VillageSystem`、`NpcScheduleSystem` | `Village`；日程瞬时投影不存档 | 世界/室内人物、碰撞、交谈 |
| 星邮与角色事件 | `MailSystem`、`CharacterEventSystem` | `Mail`、`CharacterEvents` | 邮箱、对话与奖励 UI |
| 建设施工 | `ConstructionSystem` | `Construction` | 工坊面板、小屋布局 |
| 本地化选择 | `GameSession` + `LocaleService` | `Locale` | 所有玩家可见文本 |

## 写入规则

- 单系统状态由该系统公开方法修改；外部不得直接编辑其集合或 DTO。
- 涉及库存与另一系统的动作，由 `GameSession` 编排或由领域系统接收 `Inventory` 后原子处理。
- 跨日顺序只由 `GameSession` 执行，场景不得自行推进作物、加工机、施工、邮件或天气。
- 场景切换只通过稳定 `PlayerLocationIds` 和 `GameSession.SetPlayerLocation`。
- 存档 DTO 是投影与输入，不是运行时状态所有者；恢复后由各系统重新建立合法内部状态。

## 读取规则

- `src/Game/` 读取 `GameSession`、领域只读集合、预览结果和事件。
- UI 可以缓存纯视觉引用，但不能缓存可独立演化的金币、库存、任务、NPC 或作物真相。
- NPC 当前路径和占位是由日期、时间、天气、场景和玩家格重建的瞬时状态，不进入存档。
- 地图图片、图集索引和碰撞投影不能反向决定作物成熟、设施完成、人物身份或任务进度。

## 依赖方向

```text
src/Game ───────────────→ src/Core
   │                         │
   └─ 视觉/输入/节点          └─ 规则/状态/稳定 ID

禁止：src/Core → Godot 场景节点
禁止：场景节点 → 直接修改存档 DTO 或领域集合
```

## 新功能归属判断

- “规则是否允许、会消耗什么、会得到什么”属于 `Core`。
- “当前界面显示什么、哪个节点发光、按键如何映射”属于 `Game`。
- “跨两个以上领域系统的业务动作顺序”属于 `GameSession`。
- “稳定定义和静态关系”属于数据目录或对应 Catalog。
- “仅为调试复现而存在的初始状态”属于 `PlaytestScenarioRegistry` 绑定，不进入正常业务状态。

## 禁止模式

- 在 View 中直接增减金币、体力、背包槽位或关系点数。
- 为 UI 方便复制一份可写的农业、任务、NPC 或机器状态。
- 用节点名称、翻译文本、图集坐标或场景引用作为存档身份。
- 用“读档后再修一下 UI 状态”掩盖领域归一化缺失。
