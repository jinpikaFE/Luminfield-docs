## 标准实现验证

每次相关代码改动至少执行：

1. C# 编译。
2. Core 测试。
3. 本地化键集合检查。
4. Godot headless 资源导入与主场景启动。
5. 与本次功能相关的确定性试玩入口。
6. `git diff --check`。

目标高亮、生成美术、像素缩放或布局变化还必须在当前 macOS 实际查看。存档改动必须增加新档、旧档、未知 ID、损坏数据和保存往返测试。原子动作必须覆盖成功、资源不足、容量不足、重复操作和失败零副作用。

## 试玩入口规则

- `PlaytestScenarioRegistry` 使用精确、区分大小写的 flag。
- 多个已知 flag 同时存在时，按注册顺序选择第一个。
- 无已知 flag 时保持正常标题启动。
- 场景注册表只负责选择预置状态；`Main.CreatePlaytestScenarioRegistry()` 绑定设置方法。
- 新入口必须增加目录、唯一性、优先级和正常回退测试。
- 试玩不得写死正常系统应由日程、定义或领域状态解析的结果。
- 作物图鉴六个入口固定覆盖研究台、部分发现、奖励可领取、英文已领取、错误工具与折扣商店；它们只预置发现/奖励状态，打开、领取和购买仍走正式业务路径。
- 料理图鉴五个入口固定覆盖未知、部分发现、奖励可领取、英文已领取和奖励后料理数值；它们只预置发现/奖励状态，面板、领取与食用数值仍走正式业务路径。
- 工艺品图鉴五个入口固定覆盖未知、部分发现、奖励可领取、英文已领取和奖励后货箱价值；它们只预置发现/奖励/待售状态，面板、领取与货箱估价仍走正式业务路径。
- 四季采集六个入口固定覆盖常规空手拾取、错误工具、星尘风地图标记、4/8、8/8 可领取和英文已领取；它们只预置日期、天气、发现/奖励与已探索区块，拾取、图鉴打开和地图筛选仍走正式业务路径。
- 辉晶地窟七个入口固定覆盖世界入口、基础矿脉、升级面板、深层矿脉、英文矿物图鉴、晶谷星灯面板与复苏态；它们只预置材料、工具阶级、勘探/星灯状态，进入、升级、开采、打开图鉴和星灯投影仍走正式业务路径。
- `--playtest-gleamrise-season` 预置 14 天目标进度但仍通过正式暂停菜单覆盖层读取和领取；`--playtest-fishing-donation` 预置已捐赠、可捐赠、缺少样本和未发现四态，打开与捐赠仍走正式档案馆业务路径。

- 标准三平台导出入口：`./scripts/export_all.sh`。
