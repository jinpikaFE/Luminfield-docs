# 生成素材与图集管线

## 原则

- 新增地图实体、人物、作物、物品、设施、天气表现或独立 UI 图标前，先盘点现有图集。
- 缺少合适位图时，使用内置图像生成制作原创素材；临时色块、几何图形或字符图标不是完成态。
- 素材只表达视觉，碰撞、成熟、天气、人物身份、机器状态、任务和存档仍由 Core 驱动。

## 生产流程

1. 明确用途、运行时尺寸、单元尺寸、图集行列、观察角度、落地基线、透明/色键方式和禁止项。
2. 复用现有暮色魔法农场调色板与最近邻像素密度。
3. 需要透明背景时先生成纯色色键源图，通常保存为 `*_chroma.png`。
4. 使用本地去色键流程生成透明运行时 PNG；源图和最终图都保存在 `assets/generated/`。
5. 检查裁切边界、alpha、像素密度、落地基线、近红/品红残留和最近邻缩放。
6. 通过 `GeneratedArt.cs` 或对应 View 使用稳定 ID 与确定性图集索引接入。
7. 在 `assets/generated/README.md` 记录用途、布局、提示词摘要、处理参数和接入位置。
8. 在 macOS 真实 640×360 画面检查比例、轮廓、遮挡和场景一致性。

## 文件职责

| 位置 | 职责 |
| --- | --- |
| `assets/generated/*_chroma.png` | 可追溯的色键生成源图 |
| `assets/generated/*.png` | 透明或稳定裁切后的运行时素材 |
| `assets/generated/README.md` | 布局、提示、处理和接入记录 |
| `src/Game/GeneratedArt.cs` | 加载、裁切和图集映射 |
| 各 `*View.cs` | 按领域 ID 投影到地图或 UI |

`orchard_hives.png` 是阶段 C 果树与蜂巢运行时图集，提供月梅树苗、成熟月梅树、辉巢和星蜜图标；业务状态仍由 `OrchardSystem` 与稳定 ID 驱动。

`starfeather_chickens.png` 是阶段 C 星光鸡舍与星羽鸡运行时图集，提供关闭/开放鸡舍、常态/开心星羽鸡、星羽蛋、辉光蛋乳、星谷饲料碗和心星图标；鸡舍建造、喂食、抚摸、产蛋、容量和目标计数仍由 `AnimalSystem`、`ProcessorSystem` 与 `GameSession` 驱动。

`gleamrise_festival_plaza.png` 和 `gleamrise_festival.png` 是阶段 C 芽辉播种祭场景和 4×2 图集，提供正式节日庭院、入口、播种畦、兑换摊和节徽；日期开放、进入/退出、仪式阶段、交换券和兑换状态仍由 `FestivalSystem` 与 `GameSession` 驱动。

## 稳定接入

- 图集行列、裁切矩形和角色方向顺序必须明确记录。
- 运行时索引由稳定业务 ID 映射，不能依赖字典偶然顺序。
- 生成背景不能承担碰撞；碰撞来自 `WorldDefinition`、布局或对应 Core 定义。
- 生成建筑内景不能单独决定入口、出口、开放时间或设施能力。
- 替换图集时不得改变既有稳定 ID 或存档状态。

## 完成标准

- 源图与运行时图均在仓库中。
- `assets/generated/README.md` 已同步。
- alpha 与色键残留检查通过。
- 单元裁切、落地基线和最近邻缩放经过实际检查。
- 对应领域状态、预览、碰撞和本地化测试仍通过。
- macOS 实机画面已目检；阶段 C 截图 106–112 已覆盖芽辉作物、加工机、耕作专精、果园、鸡舍、星羽鸡和播种祭。未在 Windows/Linux 实机运行时不能声称跨平台视觉通过。
