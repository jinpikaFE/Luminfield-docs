# 农业与耕作技能

## 当前范围

- 农场 48×32，种植床位置由 `FarmLayout` 定义。
- 数据目录包含 12 种植物：8 种兼容基础作物和 4 种芽辉季限定作物。
- 农业动作包括开垦、施肥、播种、浇水、天气浇灌、成长、收获、持续采收、果树种植、果实采摘、蜂巢采蜜，以及与芽辉季目标联动的动物饲料制作、首蛋收集和节日参加里程碑。
- 辉荚藤成熟后每浇水两夜再次收获；曦绫花与辉荚藤拥有天气共鸣产物。
- 三档品质为普通、莹润、星辉；稳定品质物品 ID 保留到库存、加工、委托、货箱和商店。
- 耕作技能等级 0–5；3 级永久选择守露人或共鸣学者。
- 果园系统包含芽辉季月梅树苗、三夜成熟、两夜复果，以及邻近成熟月梅树后产出星蜜的辉巢。

## 状态所有权

| 状态 | 所有者 | 关键持久化字段 |
| --- | --- | --- |
| 土壤、作物、成长 | `FarmSystem` | `Tilled`、`Watered`、`CropId`、`WateredNights` |
| 肥料与品质 | `FarmSystem` | `FertilizerId`、`QualityRoll` |
| 天气共鸣 | `FarmSystem` + `WeatherSystem` | `PlantedDay`、`ResonanceItemId` |
| 果树与辉巢 | `OrchardSystem` | `Orchard.Trees`、`Orchard.Beehives` |
| 经验与专精 | `FarmingSkillSystem` | `Experience`、`SpecializationId` |
| 14 天芽辉目标 | `GleamriseSeasonGoalSystem` | `GleamriseSeason.Goals`、`GleamriseSeason.Counters` |
| 体力与水量 | `GameSession` | `Player.Energy`、`WateringCanWater` |
| 种子与收成 | `Inventory` | 稳定物品 ID 和数量 |

## 业务路径

- 播种前检查种植床、已开垦、空地、季节限制和种子数量。
- 浇水只在合法农田成功时扣水和体力；守露人只改变成功浇水成本，最低仍为 1。
- 天气自动浇灌不消耗体力或水量。
- 睡眠时先应用洒水器，再按当天实际天气推进农田成长；之后推进机器与施工，再进入下一日。
- 品质和天气共鸣由稳定输入推导并写入农田状态，读档不得重抽。
- 单次作物收获后清除该茬肥料与稳定结果；持续采收作物在植株存续期间保留。
- 只有成功开垦、播种、浇水和收获获得经验；失败、天气浇灌和纯预览不获得经验。
- 芽辉季目标计数只接收成功业务动作：购买、播种、浇水、施肥、收获、加工启动/领取、月梅采摘、星蜜采集、星谷饲料制作、首枚星羽蛋入包和首次加入播种祭。
- 月梅树苗只能在允许季节与空闲种植床种植；果树占位会阻止其他放置物重叠。
- 月梅树成熟后用“手”采摘；采摘成功后写入复果倒计时，容量不足或工具错误不改变果树状态。
- 辉巢由制作配方产出并放在合法空地；邻近成熟月梅树后跨夜推进产蜜，采蜜成功才把星蜜放入背包并重置产蜜状态。
- 星谷饲料只在 `CraftingSystem` 成功产出后推进目标；星羽蛋只在 `AnimalSystem.CollectEggs` 成功把蛋加入背包后推进首蛋目标。

## 不变量

- 图集帧、土壤覆层或成熟外观不决定作物业务状态。
- 无效目标、季节错误、种子不足、体力不足、缺水或背包已满不消耗任何资源。
- 同一作物家族的品质可被教程、委托和加工识别，但真实品质 ID 与价值不可丢失。
- 共鸣和品质在保存/读取后保持一致。
- 新植物、动物作物链或季节目标必须同时提供稳定物品/目标 ID、双语键、成长或照料定义、商店/售价边界、图集映射和测试。

## 当前阶段边界

阶段 C 已完成 12 种植物、四种芽辉季作物、辉荚藤持续采收、两种天气共鸣、三档品质、月梅果树、辉巢产蜜、首条耕作技能、14 天芽辉季目标、星羽鸡闭环和芽辉播种祭。下一阶段从阶段 D 的钓鱼、湿地星灯与收藏开始。
