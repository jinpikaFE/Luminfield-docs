# 季节目标、动物与节日

## 当前范围

- 阶段 C / v0.4 已完成 14 天芽辉季目标、首类动物星羽鸡和第一个节日芽辉播种祭。
- `GleamriseSeasonGoalSystem` 保存芽辉季年度、目标领取态和稳定计数器；目标围绕购买、播种、浇水、施肥、采收、加工、月梅、辉巢、动物和节日推进。
- `AnimalSystem` 保存星光鸡舍、第一只星羽鸡、好感、当日喂养/抚摸、心情和待领取星羽蛋。
- `FestivalSystem` 保存第 7 天芽辉播种祭的年度、加入状态和三阶段仪式完成态，并提供芽辉交换券兑换项。
- 视觉素材包括 `starfeather_chickens.png`、`gleamrise_festival_plaza.png` 和 `gleamrise_festival.png`；业务状态仍由 Core 系统驱动。

## 状态所有权

| 状态 | 所有者 | 关键持久化字段 |
| --- | --- | --- |
| 芽辉目标领取态 | `GleamriseSeasonGoalSystem` | `GleamriseSeason.Goals`、`Year`、`SeasonId` |
| 芽辉目标计数器 | `GleamriseSeasonGoalSystem` | `GleamriseSeason.Counters` |
| 星光鸡舍与星羽鸡 | `AnimalSystem` | `Animals.CoopBuilt`、`Animals.Chickens` |
| 星羽蛋与辉光蛋乳 | `AnimalSystem`、`ProcessorSystem`、`Inventory` | `PendingEggs`、机器配方、稳定物品 ID |
| 播种祭加入与阶段 | `FestivalSystem` | `Festival.Year`、`Joined`、`CompletedStageIds` |
| 节日位置 | `GameSession` | `PlayerLocationId = gleamrise_festival` |

## 业务路径

- 芽辉目标面板由暂停菜单打开，`GameSession.GleamriseSeasonGoals()` 读取快照，`ClaimGleamriseSeasonGoal` 负责领奖。
- 目标领奖先检查目标状态、背包容量和奖励完整性；未达成、重复领取或容量不足时不改变目标、库存或货币。
- 目标只在芽辉季上下文内累计；进入下一年芽辉季时按年度重置，旧档继续保持 `schemaVersion: 1` 的加法兼容。
- 星光鸡舍由 `GameSession` 统一校验金币、材料和占位；建造成功后入住第一只星羽鸡。
- 星谷饲料只在制作成功后记录到动物目标；制作失败不会提前推进目标。
- 星羽鸡每天可被喂养和抚摸各一次；喂养消耗星谷饲料并提升好感，抚摸提升好感和心情。
- 夜间结算时，已喂养星羽鸡会增加待领取星羽蛋，上限为 3；未喂养会进入饥饿心情。
- 星羽蛋领取必须先确认背包容量，蛋成功进入背包后才记录“首蛋”目标；容量不足或无蛋不改变鸡舍状态。
- 星羽蛋可在棱彩蜜渍缸加工为辉光蛋乳；加工启动、领取和批量领取继续沿用加工机原子规则。
- 芽辉播种祭只在芽辉季第 7 天开放；从家园入口进入独立节日场景后才能推进仪式或兑换。
- 节日三阶段按固定顺序推进：铺设月石畦、播下曦绫花、调谐辉荚藤；每阶段奖励先模拟入包，失败不写入阶段。
- 节日兑换摊使用芽辉交换券兑换季节种子与星壤肥，兑换通过 `Inventory.TryExchange` 原子扣券和入包。
- 首次成功加入播种祭只记录一次目标；重复进入不会重复增加计数。

## 不变量

- `GameSession` 仍是唯一全局业务入口；场景、HUD 和节日 UI 只转发意图并展示快照。
- 交互预览和实际动作必须同源：星光鸡舍、星羽鸡、节日入口、播种畦和兑换摊都通过 `TargetPreview` 表达动作、工具、容量或日期阻塞。
- 失败动作不得扣金币、材料、星谷饲料、星羽蛋、芽辉交换券、背包槽位或目标进度。
- 首蛋目标只在星羽蛋成功入包后计数；饲料目标只在星谷饲料制作成功后计数；节日目标只在首次成功加入后计数。
- `schemaVersion` 继续为 1；新增 `GleamriseSeason`、`Animals` 和 `Festival` 投影均按加法式兼容和归一化处理未知状态。
- 生成素材不承载鸡舍、心情、阶段、兑换或目标状态。
