# 季节目标、动物与节日

## 当前范围

- `GleamriseSeasonGoalSystem` 提供按芽辉年重置的 14 天数据驱动目标板，保存稳定计数器与已领取目标 ID；遗漏或未完成目标不会造成永久惩罚。
- 目标读取真实的买种、播种、浇水、收获、施肥、加工、月梅、辉巢、动物喂养/首蛋及现有芽辉播种祭参与里程碑。
- 当前 `AnimalSystem` 统一拥有星羽鸡、月绒羊与露角兽三类动物，两栋建筑、逐只照料/成长/品质产物及分建筑自动喂收；不恢复远端旧单鸡业务模型。
- 当前芽辉播种祭是芽辉季第 4 日的十六人独立场景、十二格临时种子挑战、年度评分/奖项、花辉币与四项种子兑换；不恢复远端旧第 7 日三阶段仪式。
- 远端合并保留的 `starfeather_chickens*` 与 `gleamrise_festival*` 仅用于历史生成来源和备用构图，当前运行时不加载，也不承载业务状态。

## 状态所有权

| 状态 | 唯一所有者 | 持久化 |
| --- | --- | --- |
| 芽辉目标领取态、年度与计数器 | `GleamriseSeasonGoalSystem` | `GleamriseSeason.Year`、`SeasonId`、`Goals`、`Counters` |
| 动物、成长、心情、每日照料与品质产物 | `AnimalSystem` | `Animals.Animals` |
| 分建筑饲料/产物自动化缓冲 | `AnimalSystem` | `Animals.Automation` |
| 节日年度结果、尝试与独立货币 | `FestivalSystem` | `Festival.Results`、`PlantingAttempts`、`CurrencyBalances` |
| 玩家场景位置与跨系统原子动作 | `GameSession` | `Player.LocationId` 及各领域投影 |

## 业务路径

1. 暂停菜单打开 `GleamriseSeasonOverlay`，通过 `GameSession.GleamriseSeasonGoals()` 读取快照。
2. 目标领奖由 `ClaimGleamriseSeasonGoal` 编排；物品奖励先验证背包容量，成功后再写领取态和金币，容量不足或重复领取零修改。
3. 农业/加工/果园计数只从成功动作接入；动物喂养、首枚星羽蛋和第 4 日播种祭成功进入使用明确稳定里程碑。
4. 进入新一年的芽辉季时目标状态重置；非芽辉季仍可查看本年结果，不会清除其他农业、动物、节日或库存状态。
5. 三物种动物继续走现行建筑目录、预览/动作同源、背包容量检查与夜结算；目标系统只观察成功里程碑，不复制动物状态。
6. 芽辉播种祭继续使用现行十二格临时花田和原子兑换；目标系统只记录成功参与，不复制节日年度结果或货币。

## 不变量

- `GameSession` 是唯一全局业务入口；目标板、动物 View 与节日 UI 只展示快照、转发意图。
- 失败动作不得扣金币、材料、饲料、产物、节日货币或目标进度。
- `schemaVersion` 继续为 1；`GleamriseSeason` 是带安全默认值、未知 ID 过滤与重复记录归一化的加法字段。
- 目标计数器、动物实例、节日结果和货币都使用稳定 ID；存档不保存翻译文本或节点引用。
- 历史素材不得反向决定当前鸡舍、动物心情、挑战格、奖励、货币或年度完成状态。
